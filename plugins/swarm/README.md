# Swarm

The bundled Swarm sidecar is the native Antigravity swarm-board viewer. It reads
the language server's swarm roster, board and transcripts. It is separate from
the ChatGPT/Gemini subscription handoff provided by this fork.

See [ChatGPT + Gemini subscription handoff](../../docs/BROWSER_SESSION_AGENTS.md)
for the user-controlled workflow. It uses existing signed-in Chrome sessions,
requires no model API keys or API billing, and does not scrape provider pages.
